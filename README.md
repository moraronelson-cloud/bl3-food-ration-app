# BL3 Food Ration Control

Responsive BL3 food-ration and food-money disbursement system.

## Access roles
- Admin / Editor: manage rounds, allocations, settings, payments and proof.
- Accountant: record payments and upload/replace payment proof.
- Viewer: read-only access, reports, proof viewing and sharing.

## Ration workflow
- 14-day rounds, with historical rounds kept isolated from later rounds.
- Homepage shows each round with disbursement status first.
- Each payment can include photo proof.
- English, Français, 中文 and Lingala access screen and interface.
- Responsive phone and desktop layout.
- Supabase backend and Cloudflare Pages frontend.
